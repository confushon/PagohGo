# PagohGo
PagohGo is a Python-based console simulation system that optimizes the campus bus service for UTHM Pagoh using linked list and queue data structures. The system applies Data Structures and Algorithms (DSA), with a strong focus on linked lists, to simulate passenger queues, bus routes, and dynamic scheduling.

This project is developed as part of BWS21103 - **Data Structures and Algorithms** (Semester 3, 2025/2026)

## Sytem Features
1. Passenger queue simulation using linked lists
2. Dynamic bus scheduling
3. Route traversal between multiple stops
4. Peak vs off-peak optimization
5. Console-based user interaction

### Data Structures Used
1. **Linked List** - Core structure for routes, schedules, and queues
2. **Queue (Linked List Implementation)** - Passenger waiting lines
3. **Dictionary (Hash Map)** - Fast access to stops, buses, and routes
4. **Array/List** - Summary reports and calculated metrics

### How to Run the Program
1. Clone the repository
2. Ensure Python 3.x is installed (Python 3.9 or above recommended)
3. Run the main program file.
